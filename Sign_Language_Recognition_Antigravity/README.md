# Real-Time Sign Language Recognition and Speech Assistance System

## Overview
A real-time American Sign Language (ASL) recognition system. 
This project captures live video, detects and tracks hands using MediaPipe, and recognizes ASL gestures to construct sentences and convert them to speech.

## Objectives
- Real-time ASL alphabet recognition.
- Handling of special commands (SPACE, DELETE, CLEAR).
- Robust performance under real-world webcam conditions.
- Conversion of recognized text to speech.

## Technologies
- **Python 3.13**
- **OpenCV**: Webcam capture and image processing.
- **MediaPipe**: Hand detection and landmark extraction.
- **TensorFlow / Keras / scikit-learn**: Machine learning and deep learning models.
